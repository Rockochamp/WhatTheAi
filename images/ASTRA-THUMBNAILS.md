# Astra homepage covers · September 2026

Built-in image-generation tool, three separate square outputs, converted to WebP for the site. No text overlays. Original PNGs remain in the local generated-images folder.

- `cosmic-astra.webp`: text-to-image generation. Brief: luminous cyan triangular craft dodging fiery orange asteroids, deep violet space, strong readable arcade composition. Source `exec-7fcfc083-f131-49ab-9f44-692cee0fe335.png`.
- `hammurabi-astra.webp`: reference-image generation using the game's `kingdom.webp`. Brief: warm Mesopotamian ziggurat city, river, wheat plots, markets and citizens, composed as a living strategy kingdom. Source `exec-f91c0ee7-279b-4932-9db3-4ae36c6313ce.png`.
- `banana-astra.webp`: reference-image generation using `cover-v3.webp`. Brief: old rotten banana veteran with torn teal headband and brass seed gun, crowned meat boss and varied monsters in moonlit jungle ruins. Source `exec-8a82e041-3ff7-46cb-a6b6-1b199694e833.png`.

Each homepage version option declares its matching thumbnail. Astra covers are the default; selecting older models restores their original artwork and destination. The title already supplies each image's accessible name, so thumbnail images remain decorative.
